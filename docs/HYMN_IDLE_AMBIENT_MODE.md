# IDLE AMBIENT MONITOR MODE

When no hymn is actively playing, the monitor should not become a blank or boring screen.

## Priority
1. If a verified song is PLAYING: Music Teacher timed visual playlist owns the screen.
2. If song is PAUSED/ENDED/none: IDLE_AMBIENT owns the screen.
3. When playback resumes: switch back to the song at the next visual refresh.

## Idle visual policy
- nature-first
- slow and calm
- mix still images and short videos
- still image hold: about 24s with subtle zoom/pan
- video hold: 10–28s depending on clip duration
- soft fades only
- avoid immediate scene-family repetition
- avoid flashing / rapid cuts
- rotate across forest / water / sky / weather / vegetation / seasonal / celestial / wildlife / fire-light and newly discovered scene families

## Dynamic taxonomy
The idle mode does not use a fixed nine-scene list.
It consumes `natural_scene_taxonomy.json` and may use newly promoted scene families.

## Rights
Idle assets must be rights-cleared runtime stock or our rights-safe generated/procedural output.
Stock runtime use does not grant permission for automated ML/frame-training.

## Cost
The idle mode requires no paid generation.
Our procedural still-to-30fps animator is the first local-free custom-video route.
